5. Nginx reverse proxy

Nginx nhận HTTP trên localhost:8080, chuyển đến wordpress:80, giữ Host và đặt X-Real-IP/X-Forwarded-For/X-Forwarded-Proto. Các forwarding headers từ client bị thay bằng giá trị proxy đáng tin cậy.

HeaderTác dụng
X-Content-Type-Options: nosniffHạn chế đoán MIME type.
X-Frame-Options: SAMEORIGINHạn chế nhúng trang vào iframe ngoài origin.
Referrer-PolicyGiảm thông tin URL gửi qua referrer khi khác origin.
Permissions-PolicyTắt camera, microphone, geolocation không cần cho portfolio.
Content-Security-PolicyHạn chế frame-ancestors/object/base URI mà vẫn tương thích WordPress hiện có.

Headers dùng always, áp dụng cả phản hồi lỗi. Server tokens/PHP header bị ẩn. Chặn xmlrpc.php bằng 403, hidden files và wp-config.php bằng 404.

Listener stub_status:8088 chỉ có trong Docker network, không publish ra Windows; nginx-exporter đọc requests và connections tại đây. Không gọi probe HTTP là metrics Nginx.

docker compose exec -T nginx nginx -t
curl.exe --max-time 15 -I http://localhost:8080/

Chưa cấu hình HTTPS tự ký. Hệ thống hiện dùng HTTP và security headers cơ bản; cần đối chiếu phiếu đề bài gốc để xác nhận lựa chọn triển khai được chấp nhận.

7. Logging với Loki và Promtail

Nginx ghi access.json vào shared named volume; Promtail 3.5.0 chạy user 10001, mount logs read-only, lưu positions riêng. Loki 3.6.0 dùng schema TSDB v13 hiện có; không xóa log hoặc thay schema lịch sử.

Labels thực: project=portfolio-manh, job=nginx-access, service=nginx. Dòng JSON có timestamp, method, uri, numeric status, bytes và request_time. Query strings, cookies và Authorization không ghi vào access log.

Ba LogQL dùng trong báo cáo

{project="portfolio-manh",job="nginx-access"} | json

 | json | __error__="" | status >= 400 | status < 600

sum(count_over_time(

Đã tạo request HTTP thực: /xmlrpc.php trả 403, /.env trả 404, website trả 200. Cả ba truy vấn trả dữ liệu thực. Không cố làm hỏng upstream để tạo 5xx; truy vấn lọc được cả 4xx và 5xx theo numeric status.

Promtail EOL ngày 02/03/2026 theo Grafana. Vẫn giữ đúng công cụ theo đề. Alloy cũ được dừng và giữ volume/profile, không tự thay Promtail bằng Alloy.

Giới hạn triển khai hiện tại

HTTP với security headers, chưa TLS; MySQL exporter chỉ collectors cơ bản; cAdvisor cần đặc quyền; Nginx file logs chưa có rotation tự động. Promtail đã EOL nhưng được giữ theo checklist hiện có. Nếu sử dụng ngoài môi trường học tập, hướng phát triển là HTTPS, quản lý quyền collector, xoay file logs và chuyển sang collector còn được hỗ trợ sau khi thống nhất yêu cầu.
